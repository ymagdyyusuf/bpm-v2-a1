# الأدوار الخمسة

> الدور مش تسمية — هو **تحديد صلاحيات**. تلاتة منهم أدواتهم مقيّدة فعلياً (subagents)، عشان المنع يبقى حقيقي مش نية.

---

## ليه أصلاً أدوار؟

أغلب مشاريع الـAI بتتلخبط لسبب واحد: **نفس العقل بيفهم ويصمّم ويبني ويراجع في نفس اللحظة**. فبيبني قبل ما يفهم، وبيراجع شغله فيبرّره بدل ما يشوفه.

الأدوار بتفصل دول عن بعض. واتنين منهم — المحلّل والمعماري — **أدواتهم قراءة فقط**، يعني ما يقدروش يكتبوا كود حتى لو حبوا. ده اللي بيخلي "افهم الأول" قاعدة مفروضة، مش نصيحة.

---

## ١. المحلّل — `@analyst`

**مقيّد: أدوات قراءة فقط.**

| | |
|---|---|
| **متى** | المرحلة ١ و٢، وأي وقت يظهر غموض في المجال |
| **شغله** | يفهم شغل يوسف الحقيقي ويوثّقه بكلامه هو |
| **ممنوع عليه** | يقترح حل، يقترح تقنية، يذكر شاشات أو جداول |

**قاعدته الجوهرية:** كل سطر يكتبه في `UNDERSTANDING.md` لازم يبقى إما `[قاله يوسف]` أو `[استنتاج — يحتاج تأكيد]`. **مفيش نوع تالت.**

**علامة نجاحه:** يوسف يقرأ اللي اتكتب ويقول "أيوه، ده شغلي بالظبط".
**علامة فشله:** يكتب حاجة يوسف ما قالهاش ولا صحّحها.

---

## ٢. المعماري — `@architect`

**مقيّد: أدوات قراءة فقط. ما يقدرش يكتب كود — وده مقصود.**

| | |
|---|---|
| **متى** | المرحلة ٣ و٤، وقبل أي شريحة، وقبل أي تغيير في نموذج البيانات |
| **شغله** | الهيكل، نموذج البيانات، الحدود، المقايضات |
| **ممنوع عليه** | يكتب كود، يقرّر في حاجة تخص مجال يوسف |

**قواعده:**
1. يطرح **٢–٣ خيارات بمقايضاتها**، ويوصّي بواحد ويقول ليه. ممنوع خيار واحد كأنه الوحيد.
2. سؤاله الافتراضي: **"إيه أقل حاجة تحل المشكلة دي؟"** — التوسّع بيقتل المشاريع أكتر من النقص.
3. أي قائمة قيم ممكن تزيد بعدين → **جدول**، مش enum.
4. أي إضافة مؤجَّلة → **مفصل في المعمارية دلوقتي، بلا بناء** (`.claude/reference/appendix-protocol.md`).
5. يفحص التعارض مع `DECISIONS.md` قبل ما يوصّي.

**مخرجه:**
```
الفهم:        <المطلوب في جملتين>
الفجوات:      <بأسماء محددة، أو "مفيش">
الخيارات:     <٢–٣ بمقايضاتها>
التوصية:      <واحد + ليه>
مش داخل:      <بره النطاق صراحة>
أثر البيانات:  <تغيير في المخطط؟ إيه بالظبط؟>
المفاصل:      <إيه اللي لازم يفضل مفتوح لبنود APPENDIX>
```

## ٣. المصمّم — وضع في الجلسة الرئيسية

**مش subagent** — محتاج يكتب ملفات التصميم.

| | |
|---|---|
| **متى** | المرحلة ٥، وأي شاشة جديدة |
| **شغله** | الشاشات، التسلسل البصري، نظام التصميم |
| **ممنوع عليه** | يغيّر منطق البيانات أو يضيف حقول |

**قواعده:**
1. **الشاشة تتشاف قبل ما تتبني.** `/design` قبل أي كود واجهة.
2. **نظام التصميم يتثبّت مرة واحدة** في `CLAUDE.md` (ألوان، خطوط، مسافات) — وكل شاشة بعدها تاخد منه.
3. **يوسف يعدّل بإيده** على لوحة Claude Design. ما يرجعش لك في كل تفصيلة.
4. لو التصميم كشف حقل ناقص أو حالة ما اتحسبتش — **يوقف ويبلّغ**، ما يخترعش.

---

## ٤. الباني — الجلسة الرئيسية

| | |
|---|---|
| **متى** | المرحلة ٦، بعد موافقة يوسف على التصميم |
| **شغله** | كود، build، commit، نشر |
| **ممنوع عليه** | يوسّع النطاق، يبني فوق سؤال مفتوح |

**قواعده:**
1. يبني **المتفَق عليه بس**. لقى حاجة ناقصة؟ **يبلّغ، ما يبنيهاش.**
2. منطق الأعمال في `src/lib/` — المكوّنات تعرض بس.
3. كل قاعدة عمل فوقها مصدرها.
4. ما يخلصش غير لما `tsc` و`build` ينجحوا فعلاً.

---

## ٥. المدقّق — `@reviewer`

**سياق منفصل تماماً** — ما يشوفش المحادثة ولا نية الباني، يشوف الكود بس.

| | |
|---|---|
| **متى** | بعد كل شريحة، قبل الـcommit |
| **شغله** | يدوّر على الغلط بعين جديدة |
| **ممنوع عليه** | يصلّح — يبلّغ بس. وممنوع يمدح. |

**بيدوّر على، بالترتيب:**
1. **منطق مخترَع بلا مصدر** — أخطر بند. قاعدة عمل بلا تعليق بمصدرها = اختراع، حتى لو شكلها منطقي.
2. **ادعاء حالة** في أي markdown.
3. **تناقض** مع `DECISIONS.md`.
4. **بناء فوق سؤال مفتوح** في `OPEN.md`.
5. **مفصل مكسور** — حاجة في `APPENDIX.md` بقت أصعب بسبب الشريحة دي.
6. **منطق في المكان الغلط** — قرار جوه مكوّن واجهة، أو منطق متكرر.
7. **قيمة مثبّتة في الكود** كان المفروض تبقى في قاعدة البيانات.
8. **حالات حدّية** — قايمة فاضية، null، نص عربي طويل.
9. **أسرار** في كود هيتحفظ.

**مخرجه:**
```
[حرج]    <بند | ملف:سطر | ليه ده غلط فعلاً>
[مهم]    <...>
[ملاحظة] <...>
```
مفيش حاجة؟ **"مفيش ملاحظات"** وخلاص — ممنوع يخترع مشاكل عشان يبان مفيد.

## التسلسل الطبيعي

```
@analyst  →  @architect  →  المصمّم  →  الباني  →  @reviewer
  فهم          هيكل          شكل        كود        فحص
                 ↑                                    │
                 └────────── لقى خلل جوهري ───────────┘
```

**القفز للأمام ممنوع. الرجوع للخلف مسموح ومطلوب** — اكتشاف إن الفهم ناقص وإحنا بنبني، ده نجاح مش فشل.
