# الاختبار الذاتي

النطاق: **$ARGUMENTS** *(فاضي = الشريحة الحالية)*

---

## النتائج — مقروءة قبل ما تشوف الملف ده

فحص الأنواع:
!`npx tsc --noEmit 2>&1 | tail -20 || true`

البناء:
!`npm run build 2>&1 | tail -15 || true`

اختبارات المنطق:
!`npm test 2>&1 | tail -20 || echo "مفيش اختبارات متضبّطة لسه"`

> ظهرت كنص بدل نتيجة؟ شغّلها بنفسك — النتيجة هي المطلوبة.

---

## ١ — اقرأ النتائج فوق

أي واحد فشل → **قف واصلح**. ممنوع تكمّل الفحص وتقول "الباقي تمام".

---

## ٢ — كل قاعدة عمل ليها اختبار؟

المقياس الوحيد للتغطية (`.claude/reference/testing.md`).

1. افتح `UNDERSTANDING.md` §٤ (القواعد والممنوعات).
2. لكل قاعدة: دوّر على اختبار بيغطّيها.
3. قاعدة بلا اختبار → **اكتب الاختبار دلوقتي**، أو قول صراحة إنها مش مغطّاة وليه.

**قاعدة عمل بلا اختبار = القاعدة في راسك بس، مش في النظام.**

## ٣ — اختبار المنطق: ثلاث حالات لكل قاعدة

```
عادية  ·  عند الحد بالظبط  ·  فراغ (لا بيانات / null)
```
تلاتة. مش عشرة.

**اللي يستاهل اختبار:** دالة في `src/lib/` فيها شرط أو حساب أو تصنيف.
**اللي ما يستاهلش:** نقل بيانات بلا قرار.

## ٤ — الشاشة: ثلاث حالات، بالعين

الشريحة فيها شاشة؟ افتحها في المتصفح وشوفها في:

```
[ ] بيانات حقيقية   → بتعرض صح
[ ] فاضية           → رسالة مفهومة، مش شاشة بيضا
[ ] نص عربي طويل    → التخطيط ما اتكسرش
```

الحالة التالتة أهم واحدة بالعربي — وأكتر واحدة بتتنسي.

## ٥ — الإثبات

جملة الإثبات اللي اتكتبت قبل البناء:
> *"أقدر أفتح `<الرابط>`، أعمل `<الفعل>`، وأشوف `<النتيجة>` محفوظة **بعد إعادة التحميل**."*

**نفّذها فعلياً على الرابط الحي.** مش محلياً، ومش "المفروض تشتغل".
إعادة التحميل هي اللي بتفرّق بين حاجة اتحفظت وحاجة عايشة في الذاكرة.

## بلّغ كده

```
الأنواع:    نجح / فشل — <العدد>
البناء:     نجح / فشل
المنطق:     <ناجح>/<الكل>
التغطية:    <قواعد مغطّاة>/<قواعد موثّقة>   ← مش نسبة مئوية
الشاشة:     الثلاث حالات — اتشافت / ما اتشافتش
الإثبات:    اتنفّذ على الحي / لأ
```

أي سطر مش "نجح" = **الشريحة ما خلصتش**. ممنوع `/ship`.
