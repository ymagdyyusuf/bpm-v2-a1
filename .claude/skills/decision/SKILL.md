# تسجيل قرار

القرار: **$ARGUMENTS**

## الأول — هو قرار أصلاً؟

| هو | يروح فين |
|---|---|
| اختيار بين بدائل، اتحسم | `DECISIONS.md` ← كمّل |
| سؤال لسه مفتوح | `OPEN.md` |
| حاجة هتتضاف بعدين | `APPENDIX.md` (`/appendix`) |
| شرح لحاجة اتبنت | **ولا حتة** — الكود هو الشرح |
| مواصفة طويلة | `docs/draft/` مؤقتاً |

**محتاج فقرة عشان توصفه؟ يبقى مش قرار.**

## الصيغة

اقرأ `DECISIONS.md`، خُد الرقم التالي، وضيف **سطر واحد**:

```
| D-xx | YYYY-MM-DD | <القرار في جملة> | <ليه، في نص جملة> | <مين> |
```

## قواعد

1. **الترقيم متسلسل للأبد** — `D-07` بعد `D-06`. ممنوع نظام موازٍ (R-4).
2. **"مين"** = يوسف أو Claude.
   قرار يخص **مجال يوسف** → لازم يكون **يوسف**. لو إنت اللي قرّرته، يبقى ده خرق لـR-7 — ارجع واسأله.
3. **ممنوع علامة حالة** (R-2). الـhook هيمنعك أصلاً.
4. **ممنوع تعديل قرار قديم.** اتغيّر؟ قرار جديد يقول "يُلغي D-xx"، والقديم يفضل كتاريخ.

## بعد الكتابة

- القرار جاوب بند في `OPEN.md`؟ **امسح البند** — ما تعلّمش عليه.
- القرار قفل بند في `APPENDIX.md`؟ شيله من هناك واذكر السبب في القرار.
